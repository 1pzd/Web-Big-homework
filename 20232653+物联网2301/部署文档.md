## 一、环境准备

| 软件 | 版本要求 | 说明 |
| --- | --- | --- |
| JDK | 17 及以上 | 项目使用 Java 17 语法，必须 17+ |
| Maven | 3.6+ | 也可直接使用 IDEA 内置 Maven |
| MySQL | 8.0 及以上 | 需支持 utf8mb4 字符集 |
| IntelliJ IDEA | 2022.3+ | 社区版即可，推荐 |

> 说明：本项目为 Spring Boot 应用，内置 Tomcat，**无需单独安装 Tomcat 服务器**。

### 1.1 检查 JDK

```bash
java -version
```

应输出 `java version "17"` 或更高版本。

### 1.2 检查 MySQL

```bash
mysql --version
```

确保 MySQL 服务已启动。

## 二、导入数据库

1. 打开命令行或 Navicat / MySQL Workbench 等客户端；
2. 执行 `源代码/sql/ai_qa.sql` 脚本。

**命令行方式：**

```bash
mysql -uroot -p < "源代码/sql/ai_qa.sql"
```

**客户端方式：**

在 Navicat 中新建查询窗口，粘贴脚本全部内容并执行。

脚本会自动完成：

- 创建数据库 `ai_qa`（utf8mb4 字符集）；
- 创建 6 张表：`sys_user`、`qa_category`、`qa_knowledge`、`qa_session`、`qa_message`、`sys_config`；
- 建立唯一索引与查询索引；
- 写入 3 个初始账号、若干分类、知识库条目、系统参数与演示会话。

> 脚本开头带 `DROP DATABASE IF EXISTS`，可重复执行；重复执行会清空已有数据，请勿在生产库运行。

导入完成后可用以下命令验证：

```sql
USE ai_qa;
SHOW TABLES;
SELECT id, username, role FROM sys_user;
```

## 三、修改项目配置

用编辑器打开 `源代码/src/main/resources/application.yml`，重点确认数据源部分：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/ai_qa?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: root        # 改成你本机 MySQL 用户名
    password: 123456      # 改成你本机 MySQL 密码
```

其余配置一般无需改动：

- `server.port: 8080` —— 服务端口，若被占用可改为 8081 等；
- `ai.jwt.secret` —— JWT 签名密钥，长度需 ≥ 32 字节；
- `ai.jwt.expire: 7200` —— 登录有效期（秒）；
- `ai.engine.mode: local` —— 问答引擎模式，`local` 本地检索 / `llm` 大模型；
- `ai.engine.threshold: 0.25` —— 本地检索命中阈值，低于该值返回兜底话术。

### 3.1 （可选）启用大模型问答

若希望接入大模型，修改 `ai.engine.mode` 为 `llm` 并填写接口信息：

```yaml
ai:
  engine:
    mode: llm
  llm:
    base-url: https://api.openai.com/v1   # 任意兼容 OpenAI 协议的服务地址
    api-key: "sk-你的密钥"
    model: gpt-4o-mini
    timeout: 30000
```

> 即使 `api-key` 配置错误或网络不通，系统也会自动降级到本地知识库检索，不会导致问答功能不可用。

## 四、启动项目

### 方式一：IDEA 运行（推荐）

1. 打开 IDEA，选择 `File → Open`，选中 `源代码` 目录（即含 `pom.xml` 的目录）；
2. 等待 IDEA 自动下载 Maven 依赖（首次约需几分钟）；
3. 找到 `src/main/java/com/iot/qa/AiQaApplication.java`，右键 `Run 'AiQaApplication'`；
4. 控制台出现 `Started AiQaApplication` 即启动成功。

### 方式二：命令行运行

```bash
cd 源代码
mvn clean spring-boot:run
```

### 方式三：打包为 jar 运行

```bash
cd 源代码
mvn clean package -DskipTests
java -jar target/ai-qa-platform.jar
```

## 六、功能自测清单

建议按以下顺序验证，覆盖全部功能模块：

**前台**

1. 访问首页，确认热门问题与分类正常展示；
2. 注册一个新账号，再用该账号登录；
3. 进入问答页，输入「什么是物联网」，确认返回答案并标注来源；
4. 连续追问，确认多轮会话正常；
5. 打开历史记录，确认能看到刚才的会话与消息。

**后台**

6. 用 admin / admin123 登录后台；
7. 看板页确认各类 ECharts 图表有数据；
8. 知识库页新增一条条目，回到前台提问验证能否检索到；
9. 分类页新增 / 修改 / 删除分类；
10. 用户页禁用某个用户，确认该用户无法登录；
11. 会话页查看用户提问记录；
12. 配置页修改「命中阈值」，保存后重新提问验证生效。

## 七、常见问题

**Q1：启动报错 `Access denied for user 'root'@'localhost'`**
数据库账号密码不正确，回到第三步修改 `application.yml` 中的 `username` / `password`。

**Q2：启动报错 `Unknown database 'ai_qa'`**
数据库脚本未导入，回到第二步执行 `ai_qa.sql`。

**Q3：启动报错 `Table 'ai_qa.xxx' doesn't exist`**
脚本执行不完整，重新完整执行一遍 `ai_qa.sql`。

**Q4：端口 8080 被占用（`Port 8080 was already in use`）**
修改 `application.yml` 中 `server.port` 为其他端口，如 8081。

**Q5：中文显示乱码**
确认数据库、表、连接串均为 utf8mb4 编码；本项目脚本与配置已默认设置，一般不会出现。

**Q6：IDEA 编译报 `java: 无效的目标发行版: 17`**
IDEA 的 Project SDK 不是 17。在 `File → Project Structure → Project` 中把 SDK 与 Language Level 都设置为 17。

**Q7：问答总是返回兜底话术**
说明本地检索未命中。可检查：知识库中是否有相关内容、条目是否为启用状态，或适当降低 `ai.engine.threshold` 阈值。

**Q8：Maven 依赖下载缓慢**
在 `settings.xml` 中配置阿里云镜像：

```xml
<mirror>
  <id>aliyun</id>
  <mirrorOf>central</mirrorOf>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```
