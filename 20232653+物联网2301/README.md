## 一、项目简介

本项目是一个前后台一体的**智能问答网站**。普通用户可以在前台注册登录、就知识库提问并获得智能回答、查看历史会话；管理员可以在后台维护知识分类与知识条目、管理用户与会话、查看 ECharts 数据看板、在线修改系统参数。前后台数据全部通过 REST 接口异步交互，无页面刷新。

核心亮点是自研的**双策略问答引擎**：

- **本地知识库检索策略**：基于字符二元组 + 杰卡德相似度 + 关键词命中率加权打分，无需联网、无需 API Key，导入数据即可使用；
- **大模型策略**：兼容 OpenAI 接口协议，配置 `base-url` 与 `api-key` 即可接入任意兼容大模型；
- **自动降级**：大模型调用失败时自动回退到本地检索，保证服务不中断。

## 四、功能清单

**前台（普通用户）**

- 首页：平台介绍、热门问题、分类导航
- 注册 / 登录：随机盐 + SHA-256 密码加密，JWT 保持登录态
- 智能问答：多轮会话、实时提问、来源标注（本地知识库 / 大模型）
- 历史记录：查看本人历史会话与消息明细

**后台（管理员）**

- 数据看板：提问趋势、分类分布、来源占比、活跃用户等 ECharts 图表
- 知识库管理：条目增删改查、启用停用、命中数统计
- 分类管理：分类增删改查与排序
- 用户管理：查询、启用禁用、重置密码、角色调整
- 会话管理：查看全部会话与消息、反馈统计
- 系统配置：在线修改问答模式、命中阈值、大模型参数等

## 六、快速开始

详见 [部署文档.md](部署文档.md)。核心三步：

1. 导入 `源代码/sql/ai_qa.sql` 到 MySQL；
2. 按本机情况修改 `源代码/src/main/resources/application.yml` 中的数据库账号密码；
3. 用 IDEA 打开 `源代码` 目录，运行 `AiQaApplication`，浏览器访问 `http://localhost:8080`。
